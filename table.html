    Rules

    1. Setup. Drones D1–D6 sit on their numbered dock pads on the roof. Pick one gauge for the whole game.
    2. New needs. Each round, place a need marker on the first five called modules that are free. Skip any called module that already has a need or a dead cap.
    3. Sight. A drone sees a need if the need's module centre is within the gauge from the drone's centre. With the whole-wall gauge, it sees every need.
    4. Choose. Each drone, in order D1 to D6, takes the oldest need it can see that no earlier drone took this round. Ties: the nearest by steps, then the lowest level, then the lowest bay. If it sees nothing, it heads home to its dock.
    5. Move. Up to three steps along the grid, up or down first, then sideways. If it reaches its need, remove the marker and its rings: the module is saved.
    6. Age. Add a ring to every need left on the board. A need that would take a fourth ring dies and gets a dead cap.
    7. End. After twelve rounds, count the dead caps.
